# Acres API contracts

Generated by `npm run contracts:generate`. Keep this matrix aligned with
`openapi.json` and `schema.graphql`; CI runs `contracts:check`.

## REST

| method | canonical path | auth | notes |
| --- | --- | --- | --- |
| GET | /health | public | version-neutral liveness |
| GET | /health/ready | public | version-neutral readiness |
| GET | /api/v1/auth/csrf | public | CSRF token issue route |
| POST | /api/v1/auth/register | public + CSRF | creates account/session |
| POST | /api/v1/auth/login | public + CSRF | creates session |
| POST | /api/v1/auth/logout | session + CSRF | revokes session |
| GET | /api/v1/auth/session | optional session | anonymous or active session |
| GET | /api/v1/account | session | safe account profile |
| GET | /api/v1/regions | public | global region list |
| GET | /api/v1/regions/:slug | public | one global region |
| POST | /api/v1/forms/contact | public + CSRF | public contact form |
| GET | /api/v1/jobs/runs | session | recent scheduled jobs |
| GET | /api/v1/organizations | session | account organizations |
| POST | /api/v1/organizations | session + CSRF + Idempotency-Key | create organization |
| GET | /api/v1/organizations/:organizationId | session + organization.read | selected organization |
| PATCH | /api/v1/organizations/:organizationId | session + CSRF + organization.update | rename organization |
| GET | /api/v1/organizations/:organizationId/members | session + members.read | member list |
| PATCH | /api/v1/organizations/:organizationId/members/:membershipId | session + CSRF + members.change_role | change role |
| DELETE | /api/v1/organizations/:organizationId/members/:membershipId | session + CSRF + members.revoke | revoke member |
| POST | /api/v1/organizations/:organizationId/ownership-transfers | session + CSRF + ownership.transfer + Idempotency-Key | transfer ownership |
| GET | /api/v1/organizations/:organizationId/invitations | session + invitations.read | invitation metadata |
| POST | /api/v1/organizations/:organizationId/invitations | session + CSRF + members.invite + Idempotency-Key | issue invitation |
| DELETE | /api/v1/organizations/:organizationId/invitations/:invitationId | session + CSRF + invitations.revoke | revoke invitation |
| POST | /api/v1/invitations/accept | session + CSRF + Idempotency-Key | accept invitation |

Old unversioned product paths are removed in Phase 4 and return 404. `/graphql`
is intentionally unversioned and POST-only.

## GraphQL

| query | permission | notes |
| --- | --- | --- |
| viewer | authenticated member | safe account + active membership |
| organization | organization.read | active organization summary |
| organizationMembers(first, after) | members.read | bounded connection |
| organizationInvitations(first, after) | invitations.read | metadata only, no raw tokens |
| organizationAuditEvents(first, after) | audit.read | bounded event metadata |
| regions(first, after) | authenticated member | global public region connection |
| region(slug) | authenticated member | one global public region |

The schema has no mutation or subscription root in Phase 4.
